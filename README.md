# Responsive Number Counting Animation  
A simple and interactive web project that displays an animated number counter with a responsive design.  

## Features  
- Smooth number counting animation.  
- Fully responsive design.  
- Lightweight and easy to integrate.  

## Technologies Used  
- HTML  
- CSS  
- JavaScript
